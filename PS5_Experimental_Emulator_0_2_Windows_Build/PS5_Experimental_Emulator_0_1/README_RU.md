# PS5 Experimental Emulator 0.1 — исходный код

Это **первый запускаемый прототип оболочки для Windows 11**:
- нативное окно Windows;
- инициализация устройства DirectX 12 и swap chain;
- тёмный фон и карточки в духе консольного интерфейса;
- выбор карточек мышью или стрелками;
- карточка Grand Theft Auto VI с описанием и кнопкой «Открыть»; при выборе показывается честный статус «НЕ УСТАНОВЛЕНА», игра не запускается;
- кнопки «Открыть» и «Информация».

## Важно: чего программа пока НЕ делает
Это не эмулятор PlayStation 5. Она не исполняет игры PS5, не загружает образы PS5 и не включает GTA 6. Карточки демонстрационные. Карточка GTA VI не содержит официальную обложку Rockstar и не означает, что игра установлена. Настоящая эмуляция требует реализации CPU/GPU, системных служб, файловой системы, графических и аудиоподсистем и совместимости с конкретными играми. Нельзя обещать запуск GTA 6 на этом прототипе.

## Требования
- Windows 11 x64
- Visual Studio 2022 с workload **Desktop development with C++**
- Windows 10/11 SDK (устанавливается через Visual Studio Installer)
- CMake 3.21+ (компонент Visual Studio или отдельная установка)
- Драйвер NVIDIA для RTX 3050

## Установка и сборка через Visual Studio 2022
1. Распакуй ZIP в папку, например `C:\\Projects\\PS5ExperimentalEmulator`.
2. Открой Visual Studio 2022.
3. Выбери **File → Open → Folder...** и укажи папку проекта (в ней должен быть `CMakeLists.txt`).
4. Visual Studio автоматически обнаружит CMake-проект. Дождись завершения Configure.
5. В верхней панели выбери конфигурацию `x64-Release` или `x64-Debug`.
6. Выбери **Build → Build All**.
7. Запусти через **Debug → Start Without Debugging** (Ctrl+F5).

## Если CMake не найден
Открой Visual Studio Installer → Modify → Individual components и установи:
- C++ CMake tools for Windows
- MSVC v143 - VS 2022 C++ x64/x86 build tools
- Windows 11 SDK

## Управление
- Мышь: щёлкни карточку, чтобы выбрать.
- Стрелки влево/вправо: переключение карточек.
- Enter: открыть демонстрационную карточку.

## Структура
- `main.cpp` — Win32-окно, DirectX 12 device/queue/swap chain, карточки и обработка ввода.
- `CMakeLists.txt` — конфигурация сборки.

## Примечания
DirectX 12 в этом прототипе используется для создания устройства, очереди команд, swap chain и очистки кадра. Текст и карточки интерфейса рисуются стандартными средствами Windows поверх окна. Это позволяет получить простую рабочую оболочку без сторонних библиотек.
